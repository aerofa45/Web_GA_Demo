# Job fit and practical use case

Assessment source: the SEMO assistantship posting supplied by the user, not a verified current vacancy.

## Realistic maintenance exercise

Admissions extends a fictional program deadline from July 1 to August 15, 2027. Open Content studio, reset the sample tickets, inspect the proposed value, submit for review, request changes if needed, resubmit, approve, and publish. Verify the new date on the program page and after a refresh. Only published content patches become public locally. New tickets can update the deadline, advising contact text, and visit schedule. Tracking-only sample tickets are explicitly labeled.

The separate Java lab demonstrates structured content becoming HTML through an executed Velocity Format. Start with `npm run sandbox`, edit the fields, save XML and view the rendered preview. Reload `/preview` to verify persisted XML. It uses local tool adapters and an open-source template engine; it is not commercial Cascade CMS.

## How to present this in an interview

Show the user problem first, then the before/after content, review controls, working local publication, accessibility evidence, real Velocity execution and image export artifacts. Explain the difference between local tool adapters and the university's actual CMS. Discuss one test that found a bug and how it was fixed. Make a small change yourself and walk the reviewer through your reasoning.

Do not claim that a local simulation is a licensed Cascade instance, that miniPaint is Photoshop, that generated imagery is a real campus photograph, or that an automated score certifies WCAG compliance. The most credible portfolio combines working evidence with precise explanations.
